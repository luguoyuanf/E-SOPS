安装步骤与使用范围
  1. Android 设备按处理器选择 ARM32 或 ARM64 APK，Ubuntu ARM64 设备选择 DEB。
  2. 完成拖拽验证后下载原始安装包。Android 按设备提示允许安装；Ubuntu 使用系统软件安装器或管理员认可的方式安装。
  3. 按管理后台的终端绑定流程接入工位，核对租户、工位与任务后再投入使用。

Web 工位从后台终端入口打开。首次接入、同步和报工需要联网，设备适配应现场验证。阅读完整实施说明 · 免费范围与扩容
